## 结论

- **零漂移**: 10+ 轮修复 (微尺度相对化 / 载荷与输入校验 / 契约清账 / 复查轮)
  全部只动了 API 边界与错误路径, 正常路径数值结果逐位不变 — 与"行为冻结区"
  设计目标一致。
- **验证方法说明**: 两版本均直接 import 同一 .msh 文件 (不经 gmsh 重新网格化),
  消除网格生成差异; BC 用坐标 + 纯拓扑施加, 消除边界分类路径差异;
  因此任何 >0 的差异必然来自求解链路本身 — 实测全部为 0。
- **早期版本 .spec 输入不可用** (9.18.1 才修复 .spec 扩展名回归) — 本对照
  统一用 .msh 输入避开该历史 bug, 不影响数值对照的有效性。
